# RentLab


## 📌 Project Overview

RentLab is a web-based Rental Management System that allows users to list, browse, and rent items such as vehicles, electronics, and properties. The system supports multiple roles including Admin, Owner, and Renter, making it a complete rental solution.

---

## 🚀 Features

### 👨‍💼 Admin

* Manage rental owners and customer accounts
* Oversee rental inventory and system data

### 🏪 Owner

* Add, update, and remove rental items
* Track ongoing rentals with customer details
* Monitor overdue rentals

### 👤 Renter

* Browse items with images and descriptions
* Search and filter items by category and price
* Request rentals and manage account
* View rental history and request status

---

## 🛠️ Technology Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** PHP
* **Database:** MySQL
* **Server:** XAMPP (Apache)

---

## ⚙️ How to Run Locally

1. Install XAMPP
2. Move project to:

   ```
   C:\xampp\htdocs\WEBTECHPROJECT
   ```
3. Start Apache & MySQL
4. Open browser:

   ```
   http://localhost/WEBTECHPROJECT
   ```
